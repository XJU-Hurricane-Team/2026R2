# 2026R2 上位机调用接口说明文档

## 概述

本文档描述上位机通过 MicroROS 与下位机通信的接口规范。所有控制命令通过 ROS2 Service `/control_dispatch_srv` 发送。

**Service 类型**: `custom_msg/srv/ControlDispatch`

**请求消息结构**:
```
int8 event          # 模块选择 (0:夹爪, 1:机械臂, 2:抬升)
int8 command_mode   # 命令模式
geometry_msgs/Point point  # 坐标点 (机械臂动态抓取时使用，单位: m)
```

**响应消息结构**:
```
bool success
```

---

## 1. 底盘模块 (Chassis)

### 1.1 接口说明

底盘控制通过订阅导航主题实现，非 Service 接口。

**订阅主题**: `/nav_speed_heading_data`

**消息类型**: `custom_msg/msg/SpeedHeading`

### 1.2 消息结构
```
float32 linear_x    # X方向线速度 (m/s)
float32 linear_y    # Y方向线速度 (m/s)
float32 angular_z   # 角速度 (rad/s)
```

### 1.3 注意事项
- 底盘有两种工作模式：手动模式（遥控器控制）和自动模式（导航控制）
- 自动模式下导航消息才会生效
- 可通过 LED1 判断模式：亮=自动模式，灭=手动模式

## 2. 夹爪模块 (Catch)

### 2.1 接口说明

**event 值**: `0`

### 2.2 command_mode 定义

| command_mode | 功能 | 说明 |
|-------------|------|------|
| 0 | 初始化 (INIT) | 夹爪复位到初始状态 |
| 1 | 准备就绪 (READY) | 夹爪进入准备状态，等待识别 |
| 2 | 识别模式 (RECOGNIZE) | 触发视觉识别流程 |
| 3 | 检查状态 (CHECK) | 检查当前状态 |
| 4 | 完成状态 (DONE) | 标记任务完成 |

### 2.3 状态流转
```
INIT(0) -> READY(1) -> RECOGNIZE(2) -> CHECK(3) -> DONE(4)
```

---

## 3. 机械臂模块 (Robot Arm)

### 3.1 接口说明

**event 值**: `1`

### 3.2 command_mode 定义

| command_mode | 功能 | 说明 |
|-------------|------|------|
| 0 | 初始化状态 (INIT) | 机械臂回到零点初始姿态 |
| 1 | 准备状态 (READY) | 进入准备抓取姿态 |
| 2 | 动态抓取 (CATCH) | 根据坐标点执行动态抓取 |
| 3 | 放置状态 (PLACE) | 执行放置动作 |
| 4 | 待取出状态 (WAIT_TAKEOUT) | 等待取出物品 |
| 5 | 取出状态 (TAKEOUT) | 执行取出动作 |

### 3.3 坐标点参数 (command_mode=2 时使用)

当 `command_mode = 2`（动态抓取）时，需要通过 `point` 字段传入目标坐标：

| 字段 | 单位 | 说明 |
|------|------|------|
| point.x | m | 目标 X 坐标 |
| point.y | m | 目标 Y 坐标 |
| point.z | m | 目标 Z 坐标 |

### 3.4 机械臂状态说明
- **INIT**: 回到机械零点
- **READY**: 准备姿态，等待抓取指令
- **CATCH**: 执行抓取动作，需要配合坐标点使用
- **PLACE**: 将物品放置到指定位置
- **WAIT_TAKEOUT**: 等待上位机取走物品
- **TAKEOUT**: 执行取出动作

---

## 4. 抬升模块 (Lift)

### 4.1 接口说明

**event 值**: `2`

### 4.2 command_mode 定义

| command_mode | 功能 | 说明 |
|-------------|------|------|
| 0 | 上台阶模式 | 底盘进入上台阶动作序列 |
| 1 | 下台阶模式 | 底盘进入下台阶动作序列 |

### 4.3 注意事项
- 抬升动作执行期间，除急停按键外，其他底盘按键操作将被禁止
- 可以通过 `/stair_topic` 主题订阅台阶动作状态反馈
- 台阶动作状态使用 `std_msgs/Int8` 发布

---

## 5. 状态反馈主题

### 5.1 控制状态反馈

**主题**: `/control_dispatch_topic`

**类型**: `std_msgs/Int8`

**说明**: 发布控制调度状态

### 5.2 台阶状态反馈

**主题**: `/stair_topic`

**类型**: `std_msgs/Int8`

**说明**: 发布台阶动作执行状态

---


## 6. 错误处理

- Service 调用返回 `success = false` 表示命令执行失败
- 可通过 `/log/msg` 主题查看详细日志信息
- 可通过 `/log/data` 主题查看实时数据（Float32MultiArray 类型）
